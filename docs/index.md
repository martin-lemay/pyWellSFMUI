# pyWellSFMUI

**pyWellSFMUI** is a web-based interface for the [pyWellSFM](https://github.com/martinlemay/pyWellSFM) stratigraphic forward modeling simulator. It lets you create, edit, and run 1-D stratigraphic simulations entirely in your browser.

The app is organized into three main sections accessible from the sidebar:

1. **Well Data Analysis** -- Load wells, define a facies model, compute accommodation curves, and compare results across wells.
2. **Simulation** -- Build a complete simulation scenario (accumulation model, eustatic curve, depositional environments, realization data) and run the forward model.
3. **Visualization** -- Inspect simulation outputs: elevation profiles, production rate plots, and well log comparisons.
