# pyWellSFMUI

Web-based UI for the pyWellSFM stratigraphic forward modeling simulator.

## Setup

```bash
pip install -e ../pyWellSFM
pip install -e ".[dev]"
```

## Run

```bash
panel serve src/pywellsfmui/app.py
```
